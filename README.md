¿Qué es Plant Care?

Plant Care es un proyecto STEAM que propone un invernadero inteligente diseñado para facilitar el cuidado de las plantas mediante sensores, programación y mecanismos automatizados.

Problemática

Muchas personas tienen dificultades para cuidar sus plantas cuando no están en casa. Además, los cambios climáticos pueden afectar su crecimiento y aumentar la necesidad de supervisión.

Nuestra solución

Desarrollamos un prototipo que integra:

- Sensor de humedad del suelo.
- Sistema de riego automático.
- Monitoreo de temperatura.
- Sensor de nivel de agua.
- Servomotores para abrir y cerrar las ventanas.
- Microcontrolador programable.

Objetivo

Facilitar el cuidado de las plantas y promover un uso eficiente del agua mediante la aplicación de tecnología.

Enfoque STEAM

- Science: Necesidades de las plantas.
- Technology: Sensores y programación.
- Engineering: Diseño y construcción del prototipo.
- Arts: Diseño visual del invernadero.
- Mathematics: Medición y análisis de datos.

Objetivos de Desarrollo Sostenible

- ODS 6: Agua limpia y saneamiento.
- ODS 9: Industria, innovación e infraestructura.
- ODS 12: Producción y consumo responsables.
- ODS 13: Acción por el clima.

Estado del proyecto

Prototipo desarrollado para la Liga Educativa de Robótica 2026. Las funciones de automatización y control requieren documentación de sus pruebas de funcionamiento.

Conclusión

Plant Care busca demostrar cómo la tecnología puede contribuir al cuidado de las plantas, la innovación y la sostenibilidad ambiental.
